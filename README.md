# Ce dépôt

Ce dépôt regroupe deux projets indépendants :

- **Kick Clean** (racine du dépôt : `index.html`, `services.html`, `galerie.html`,
  `a-propos.html`, `contact.html`, `style.css`) — site vitrine statique pour une
  entreprise de nettoyage de sneakers à Ouagadougou.
- **[ProxiServices](proxiservices/README.md)** (`proxiservices/`) — ébauche de
  plateforme de mise en relation pour services de proximité (backend FastAPI +
  frontend statique). Voir `proxiservices/README.md` pour l'architecture complète,
  les instructions de lancement et la liste de ce qu'il reste à construire.
